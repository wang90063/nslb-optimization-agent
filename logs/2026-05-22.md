## 详细记录

### 今日结论

1. 直接把 `base_cbt==0` 从所有 `main PC` 里砍掉（`v169`）会伤第一轮 group-level merge 的有效收益，`submit_core` 直接掉到 `1084.66`，不成立。
2. 真正有害的位置更像是 `refine` 之后的 revisit `main PC`。`v170` 把 `proxy_11` 从 `67.89` 修到 `68.49`，`contrast` 提到 `446.36`，固定对抗集 `bench_1 + proxy_4/8 + medium_31/32 = 307.32`，相对 `v163` 的 `307.31` 非负。
3. 但 `v170` 的 `submit_core` 只有 `1085.34`，仍比 `v163` 的 `1085.36` 低 `0.02`，所以它更适合作为“revisit PC 的坏链定位分支”，还不够替换当前主线。
4. 再把限制收窄到“只作用于额外交替链”（`v171`）后，`proxy_11` 继续涨到 `68.53`，但 `medium_31` 的 `Maxmultir` 从 `10.00` 回到 `10.50`，固定对抗集总分降到 `375.65`，说明问题不只在最深那两轮额外链上。
5. 当前更可信的下一步不是继续调粗 gate，而是把 revisit `main PC` 的候选质量再结构化：至少区分“第一轮 `refine` 刚把 card 修平”和“原本就 `base_cbt==0` 的 card”，避免把后者继续卷进交替链。
6. `v178` 进一步确认：**overloaded-cell / `jm-gap` 这条 low-r 结构线是对的**。hot-cell exact single-flow move 能把低 `r` 诊断集从 `521.13` 拉到 `521.18`，但仍没有把 `Maxsingler` 真正压下去，也没有转成主口径净增。
7. `v179/v180` 说明当前的 generic coordinated beam 还不够成熟：直接拿 beam 替换 exact 会退；把 beam 叠在 exact 后面也只能追平 `v178`。因此下一步如果还沿 `jm-gap` 往下做，重点应是 **更小、更精确的 saturated-component / multi-flow exact core**，而不是更宽的 beam。

   - 但当前 overloaded-cell core 的实现还不够强，只够把错误触发收掉，还没带来额外净增量

### v185 cross-dest swap + overflow-aware scoring + single-flow move

1. 改动（基于 `v163` 干净基线）：
   - 新增 `run_cross_dest_swap(m)` operator：跨不同 dest leaf 的流互换端口，减少 Cbtphsc
   - 核心思路：对 Cbtphsc > 0 的 card，找到其 dominant port，把非 dominant port 上的流与 dominant port 上其他 card 的流互换
   - 与 `relaxed_swap` 的区别：`relaxed_swap` 要求同 `(sl, dl)` 对，`cross_dest_swap` 只要求同 source leaf，候选空间大 ~31x
   - max-phase-load 约束：swap 后任何 `(leaf, port)` 的 per-phase load 不超过当前 max，防止 MM 回退
   - overflow-aware 加权评分：`wt = 5*cbtphsc_delta - 12*overflow_delta`，同时优化 Cbtphsc 和 Cinphsc
   - 单流移动补充：swap 后再做 single-flow move pass，把有 load slack 的流直接移到 dominant port
   - 无参数门控：对所有 `(p, r)` 组合生效
   - 调用位置：`relaxed_swap -> neutral_swap -> relaxed_swap -> cross_dest_swap`
2. 逐 case 对比（vs v163 baseline）：
   - proxy_1 (p=8,r=4): Cbtphsc 2211→2161, Cinphsc 402→397, score +0.01
   - proxy_4 (p=8,r=4): Cbtphsc 2024→1981, Cinphsc 849→845, score +0.01
   - bench_15 (p=8,r=4): Cbtphsc 2273→1978, score +0.10
   - medium_25 (p=16): score +0.20
   - medium_32 (p=16): score +0.08
   - proxy_10 (p=16): score +0.04
   - medium_31 (p=8,r=2): Cbtphsc 2049→1983, MM 10.00→10.00, score +0.03
   - 所有 p=32 case：持平，零退化
   - **全部 19 个 submit_core case 零退化**
