## 详细记录

### v47 Maxmultir 优化（线上 +3.8）

核心改动：
1. eval修改：jm≤r时切换为fg优先 `fg*10000 + jm*100 + ci`
2. Global-dominant策略(S11-S13): local_w=1, global_w=3/5
3. Future-gmax greedy(S14-S15): `cost = local_max + global_accumulated*3`
4. LNS: 找全局瓶颈port上的流，拆除后重新分配
5. 自适应global权重(S6b): `adaptive_gw = 1 + (job_idx*3)/n`

### v49 FTRL greedy

新增 `run_greedy_ftrl`: `cost = local_max*2 + gv + gv²/scale`
二次惩罚自然抑制全局过载，作为ensemble候选更安全。

### v62 proxy导向策略选择（线上 +3.36，当前最佳）

两个技术改动：
1. **`eval_strategy` → `collect_metrics` + `better_metrics`**
   - 逐层比较: score_jm → score_fg → ci → future_over → future_sq → jm → fg
   - 新增 `future_over = sum(max(global+local_max-r, 0))`
   - 新增 `future_sq = sum(fo²+fi²)`

2. **4个local-first hardcap候选(S6e2-S6e5)**
   - `run_greedy(m, 1000, 1, 1)` 正序/逆序 × 带/不带swap
