## 详细记录

### 线上数据集特征推断

| 通信模式 | 占比(推测) | swap 有效性 |
|----------|-----------|------------|
| Ring AllReduce | ~60% | 无效 |
| All-to-All (MoE) | ~15% | 可能有效 |
| Skewed All-to-All | ~10% | 有效 |
| Pipeline | ~15% | 无效 |

参数多样性：线上可能有 p=4/8/16 混合。

### v11-v16 本地实验

| 版本 | 方案 | 结果 |
|------|------|------|
| v11 | popcount排序+迭代瓶颈修复 | 多cell同时在max，无法突破 |
| v12 | multi-start随机排序 | 收敛相同结果 |
| v13 | sum-of-squares代价 | 不影响瓶颈 |
| v14 | leaf-pair分组排序 | 结构化+1，随机-3 |
| v15 | 反向re-greedy | 唯一微小改善 |
| v16 | sum-global惩罚 | 严重退化，废弃 |

### v34-v39 冲突优化（全部失败）

| 版本 | 方案 | 结果 | 原因 |
|------|------|------|------|
| v34 | card-port affinity tiebreaker | -0.14 | 干扰负载均衡 |
| v35 | 后处理移流到卡主端口(≤job_max) | -23.93 | Cinphsc暴涨 |
| v36 | 全局最大端口额外惩罚 | -9.29 | 局部失衡 |
| v38 | 严格tiebreaker(仅cost相同) | -0.14 | 收益太小 |
| v39 | 移流到卡主端口(≤r) | -9.84 | Maxmultir恶化 |

**根本结论：** 代价/收益比≈750:1，任何流合并都是净亏损。

### v43 ensemble 机制

- S1: 标准 greedy (local_w=2, global_w=1) + swap
- S2: hardcap greedy (超r加10000惩罚) + swap
- S3: 反序 + hardcap greedy + swap
- 评估: `jm*10000 + fg*100 + ci`，per-job独立选最优
- 关键收益: mixed3/4 Maxsingler 1.25→1.00 (+8 each)

### MoE 通信模式场景分析

极端 MoE 是信息论极限（Maxmultir 20-53），线上不是极端 MoE。
线上更可能是中等负载混合模式（DP Ring + 轻度 EP + Pipeline），Maxmultir 5.5-11.0。
